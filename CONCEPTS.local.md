# Concepts — discuss appendix

discuss vocabulary appended to the canonical qq glossary linked at
`CONCEPTS.md`. Read both before every work item. Definitions here never
redefine a canonical term.

**main post** — The operator's primary discussion contribution for a week
(typically a few hundred words): a stance and supporting evidence in the
operator's own voice, drafted with Claude's assistance.

**classmate replies** — The two required responses to other students' posts
each week. Drafted (never auto-generated without input) and saved for the
operator to paste manually under the specific classmates' posts.

**soonest-due discussion** — The discussion thread with the nearest upcoming
due date in the target class; the single trigger navigates the operator's
already-logged-in portal session there.

**portal** — The UOPX Blackboard Ultra student portal; a login-gated surface
the tool never automates credentials for.

**draft-only** — The tool's invariant: it fills reply fields or saves drafts
and stops. No run path ever locates or clicks a submit control; the operator
alone reviews and posts.

**single source of truth** — `intent.md` is the project's ratified
foundation; no implementation or workflow contradicts it.
